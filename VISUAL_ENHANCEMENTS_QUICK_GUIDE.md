## 🎬 Animation Examples

### Card Hover
```css
Initial:    box-shadow: var(--shadow)
On Hover:   box-shadow: var(--shadow-md)
            transform: translateY(-3px)
Result:     Smooth lift effect
```

### Button Hover  
```css
Initial:    background: linear-gradient(accent)
On Hover:   box-shadow: 0 6px 16px rgba(accent, 0.35)
            transform: translateY(-1px)
Result:     Glowing elevated effect
```

### Modal Entry
```css
Animation:  slideUp 0.25s ease-out
Effect:     Smooth entry from bottom with fade-in
Result:     Professional appearance
```
